What the project does

Sitio demostrativo del proyecto. La aplicación es schema-driven: cada formato se describe como un esquema y el motor (frontend + PDF) lo interpreta, de modo que agregar un formato no obliga a tocar el núcleo.

Módulos de la plataforma

Funcionalidades disponibles según el rol del usuario.

Gestión de formatos

Catálogo navegable con los 7 formatos, búsqueda y filtro por estado en tiempo real.

CRUD de registros

Alta, edición, eliminación y duplicado con formularios renderizados desde el esquema.

Ciclo de estados

BORRADOR → CONCEDIDO / NO CONCEDIDO / CANCELADO, con regla de negocio automática.

Generación de PDF

Render en servidor con Puppeteer, respetando el diseño del formato físico original.

Trazabilidad

Historial por registro: quién creó, editó o cambió el estado, con fecha y detalle.

Tablero de indicadores

KPIs por formato con filtros de rango de fechas y exportación a CSV.

Validación estricta

Campos obligatorios, rangos numéricos, fechas no futuras, tablas y checklists completos.

Gestión de usuarios

El Coordinador crea accesos para subalternos SISO; cada uno entra con su propio correo.

Perfil de usuario

Foto de perfil (con redimensión automática), nombre, cargo, cédula y teléfono, editables desde el panel.

Cada formato conserva el contenido, los checklists y el orden del documento físico original.

Roles y permisos

Dos perfiles con alcances distintos, aplicados en la interfaz y validados en la API.

Coordinador SST

  • Ve todos los registros de todos los formatos
  • Aprueba (CONCEDIDO) y cancela permisos
  • Elimina registros
  • Accede al tablero de indicadores globales
  • Exporta CSV
  • Crea y administra accesos de subalternos SISO

SISO

  • Crea y diligencia registros en campo
  • Ve únicamente los registros que él creó
  • Genera el PDF de sus propios registros
  • Si una respuesta es NO, el estado queda en NO CONCEDIDO
  • Sin acceso a eliminación ni a indicadores globales

Cómo ejecutarla

Requiere Node.js 18 o superior. La aplicación corre en http://localhost:3200.

# 1. Instalar dependencias (solo la primera vez)
cd "Proyecto/platform"
npm install

# 2. Cargar usuarios y registros de demostración
npm run seed

# 3. Arrancar el servidor
npm start

npm run seed crea 2 usuarios de demostración y 24 registros repartidos en los 7 formatos (CONCEDIDO, NO CONCEDIDO, BORRADOR y CANCELADO) con datos realistas y fechas recientes.

Nota sobre la publicación

Esta página es estática y vive en GitHub Pages. La plataforma con login, base de datos y generación de PDF necesita un servidor Node.js en ejecución, por lo que no puede alojarse en GitHub Pages: para publicarla con functionality completa se requiere un hosting de Node (por ejemplo Render o Railway).
